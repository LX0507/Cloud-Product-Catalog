# 智能家居在线报价系统（SmartQuotationSystem Web）的云端产品库

[![GitHub](https://img.shields.io/badge/GitHub-LX0507%2FSmartQuotationSystem--Web-181717?logo=github&style=flat-square)](https://github.com/LX0507/SmartQuotationSystem-Web)

面向智能家居行业的**在线报价 + 方案设计**单页应用（SPA）。支持产品库管理、快速报价、毛利核算、户型图设备点位标注，并可一键将方案点位同步为报价单。
